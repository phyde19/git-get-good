# What's in the git dot directory?

### .git/refs/heads <- heads to branches
```bash
phyde19@fedora:~/learn/git/.git/refs/heads$ ls 
main  new_branch
phyde19@fedora:~/learn/git/.git/refs/heads$ cat main
87f216b88b25a46bf8d9cbccd38732c7e5ec5483
```

### .git/HEAD
```bash
phyde19@fedora:~/learn/git/.git$ cat HEAD
ref: refs/heads/new_branch
```
